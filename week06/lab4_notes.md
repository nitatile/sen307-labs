In Part 4 of the practical, attempting to delete a parent department that still had a registered student triggered Error 1451 (Foreign Key Constraint Failure). MySQL refuses this operation because maintaining referential integrity prevents orphaned child records (students pointing to a non-existent department `dept_id`). To resolve this safely without losing student records, we first updated the dependent student's `dept_id` to point to an active department (Software Engineering), after which the deletion of the empty department succeeded smoothly. Alternatively, this could also be resolved by setting up the foreign key with an `ON DELETE CASCADE` or `ON DELETE SET NULL` rule, which automatically removes or nullifies dependent foreign keys when the parent record is deleted.
